🔹 Overview

->This project analyzes an employee dataset from ABC Company containing 458 rows and 9 columns. The main objective is to preprocess the data, perform analysis, and visualize key insights about employees across different teams, positions, age groups, and salary distribution.

🔹 Data Preprocessing

-> Missing values in the Salary column were handled using mean values
-> The height column was corrected by assigning random values between 150 and 180
-> Data was cleaned to ensure consistency and accuracy


🔹 Analysis Performed

-> Distribution of employees across teams
-> Percentage contribution of each team
-> Segregation of employees based on positions
-> Identification of predominant age group
-> Salary expenditure by team and position

🔹 Visualizations

-> Bar charts for team and position distribution
-> Bar chart for age group analysis
-> Bar charts for salary expenditure

These visualizations help in understanding patterns and comparisons clearly.

🔹 Key Insights
-> Some teams have a higher number of employees than others
-> Certain positions are more common within the company
-> Most employees belong to a specific age group
-> Salary expenditure is higher in certain teams and roles
🔹 Tools Used
-> Python
-> Pandas
-> NumPy
-> Matplotlib
-> Seaborn


🔹 Conclusion

->This project provides insights into employee distribution, workforce structure, and salary allocation. It helps in better understanding organizational patterns and supports decision-making.
